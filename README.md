## About the Game

Welcome to **Three Body Problem**, a thrilling 2D platformer game developed with the powerful [Godot Engine](https://godotengine.org/). This game offers an immersive gameplay experience complemented by electrifying visuals and captivating challenges.

### Key Features
- **Engaging Gameplay**: Immerse yourself in the intricacies of the Three Body Problem universe through puzzle-solving and skill-based challenges.
- **Beautiful Graphics**: Stunning backgrounds and meticulously designed game environments.
- **Customizable Settings**: Tailor your experience with adjustable music volume, sound effects, and keyboard inputs, as shown below:
